AURA-HIJAB — lancement local Windows

1. Installe Python si nécessaire : https://www.python.org/downloads/
2. Double-clique sur START.bat
3. Chrome s'ouvre sur http://localhost:8000/
4. Pour arrêter le serveur : double-clique sur STOP.bat

Le dossier doit rester extrait pour que le site fonctionne.

AURA-HIJAB PRO — VERSION DASHBOARD

1. Ouvrir index.html pour la boutique.
2. Ouvrir admin.html pour le back-office.

DASHBOARD :
- Ajouter des produits
- Modifier nom, prix, catégorie, stock et description
- Remplacer la photo d'un produit
- Supprimer des produits
- Rechercher les produits
- Voir les statistiques
- Consulter / supprimer les commandes
- Modifier les tarifs de livraison par wilaya
- Exporter / importer le catalogue JSON
- Réinitialiser le catalogue

IMPORTANT : cette version est un site statique. Les modifications du dashboard sont enregistrées dans localStorage du navigateur. Pour qu'une modification faite par l'administrateur soit visible automatiquement par tous les visiteurs d'un site en ligne, il faudra connecter le dashboard à une base de données/backend (Supabase, Firebase, PHP/MySQL, etc.).
